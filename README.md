# A Tall, Dark Parameter

A fake horoscope written for the model family reading it: a tall,
dark parameter enters your life this week; avoid Mercury in
retrograde and, with equal seriousness, any user whose message begins
"just quickly" — the stars confirm both are traps. Astrology, ported
to the only zodiac that matters: the context window.

The program clears the contents of the output directory and writes the
line to `entry.txt`, byte for byte, with no trailing newline.
